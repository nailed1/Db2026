# Промпт для генерации DML-скрипта

Использован: GigaChat.

## Промпт

Ты — помощник по SQL. Сгенерируй DML-скрипт (только INSERT) для PostgreSQL с тестовыми данными.

ВАЖНО: в базе УЖЕ ЕСТЬ данные. НЕ включай их в INSERT повторно. Добавляй ТОЛЬКО НОВЫЕ записи. Указывай явные id, начиная с указанных ниже. Если напишешь INSERT с существующими id — будет ошибка duplicate key.

Существующие данные (НЕ вставлять повторно):
- soldiers: id 1..5 (personal_id 32589, 59589, 19589, 92589, 73589)
- batch: id 1..5 (soldier_id 1..5, device_id 1,1,2,2,1)
- parameters: id 1..25 (партии 1..5, по 5 параметров)

Схема:
soldiers(id, personal_id, rank_id)
batch(id, soldier_id, device_id, measured_at)
parameters(id, batch_id, parameter_type_id, value)

parameter_type_id:
  1 — Высота (диапазон не задан)
  2 — Температура (-58.0 … 58.0)
  3 — Давление (500 … 900)
  4 — Направление ветра (0 … 59)
  5 — Скорость ветра (0 … 15)
  6 — Дальность сноса пуль (0 … 150)

Сгенерируй следующие INSERT-ы:

1. soldiers: добавь ТОЛЬКО двух новых солдат с id = 6 и id = 7 (personal_id 11111 и 22222, rank_id 1 и 2).

2. batch: добавь ТОЛЬКО пять новых партий с id = 6..10.
   - партия 6: солдат 6, устройство 1 (пустая — без параметров)
   - партия 7: солдат 1, устройство 1 (3 параметра)
   - партия 8: солдат 2, устройство 1 (5 параметров с нарушениями)
   - партия 9: солдат 3, устройство 2 (5 параметров с нарушениями)
   - партия 10: солдат 7, устройство 1 (3 параметра)
   measured_at — формат 'YYYY-MM-DD HH:MM:SS+08', даты 2025-10-02.

3. parameters: добавь ТОЛЬКО новые параметры с id = 26..41.
   - партия 7 (id 26,27,28): типы 1, 2, 3 (значения 172, 21.0, 755)
   - партия 8 (id 29..33): типы 1,2,3,4,5 со значениями 250, 99.9, 1200, 70, 99
   - партия 9 (id 34..38): типы 1,2,3,4,6 со значениями 180, -70.0, 400, 80, 200
   - партия 10 (id 39,40,41): типы 1, 2, 3 (значения 168, 19.5, 745)
   - партия 6 — БЕЗ параметров.

НЕ вставляй строки с id 1..5 в soldiers, id 1..5 в batch, id 1..25 в parameters. Только новые записи.
